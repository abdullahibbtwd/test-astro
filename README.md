# Astrology app

Start with the [frontend team handoff](FE/FRONTEND_TEAM_HANDOFF.md), dated 6 October 2026.

This repository contains the Expo/React Native app, its private preview API, deterministic astrology calculations, reading layers and Personal Astrologist. The Android development preview works with real calculations/readings; it is not a production release.

Remaining priorities: payment policy and implementation, UX/UI refinement in the current design direction, and native iOS completion. The handoff also records hosting, multiuser and release dependencies.

- [New-developer setup](FE/handoff/SETUP.md)
- [Workstreams and decisions](FE/handoff/REMAINING_WORK.md)
- [Verification and acceptance](FE/handoff/ACCEPTANCE.md)
- [Current design direction](FE/handoff/DESIGN_DIRECTION.md)

Use the complete repository, not just FE. The private fixture ZIP is included at `FE/handoff/frontend-demo-fixtures.zip`; extract it as described in the setup guide before starting either API. Obtain the original design kit from Radul. Credentials, live account data and SDK installations are intentionally not shipped.
